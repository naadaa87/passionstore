# 열정상회 검색 노출 가이드

홈페이지를 공개한 뒤 네이버·구글·다음에 잘 노출되도록 하기 위한 운영 안내입니다.
사이트 안의 기술적인 준비(제목·설명, 구조화 데이터, 사이트맵, RSS, robots.txt)는 이미 되어 있습니다. 아래는 사람이 해야 하는 일입니다.

## 2. 공개 직후 할 일 (순서대로)

### ① Cloudflare 빌드 설정 확인

Cloudflare → Workers & Pages → 이 프로젝트 → Settings → Builds

- Build command: `node tools/build.js`
- Build output directory: `public`

이 설정이 있어야 `site.json`과 상회보 글을 고쳤을 때 사이트에 반영됩니다.

### ② 네이버 서치어드바이저

1. [searchadvisor.naver.com](https://searchadvisor.naver.com) → 웹마스터 도구 → 사이트 등록에 사이트 주소를 넣습니다.
2. 소유확인 방법에서 **HTML 태그**를 고르고, `content="..."` 안의 값만 복사합니다.
3. GitHub에서 `site.json`을 열어 `"naver": ""` 따옴표 안에 붙여 넣고 Commit changes를 누릅니다.
4. 1~2분 뒤 서치어드바이저에서 소유확인을 누릅니다.
5. **요청 → 사이트맵 제출**: `https://주소/sitemap.xml`
6. **요청 → RSS 제출**: `https://주소/rss.xml`
7. **검증 → robots.txt → 수집요청**을 누릅니다.
8. **요청 → 웹 페이지 수집**에 홈, 가입 안내(`/join`), 장날(`/jangnal`), 대상별 페이지 네 곳(`/for/shop-owners` 등)을 하나씩 넣습니다.

### ③ 구글 서치 콘솔

1. [search.google.com/search-console](https://search.google.com/search-console) → 속성 추가 → **URL 접두어**에 사이트 주소를 넣습니다.
2. 확인 방법에서 **HTML 태그**를 고르고 `content` 값만 복사해 `site.json`의 `"google"`에 넣습니다.
3. 확인을 누른 뒤 **Sitemaps** 메뉴에 `sitemap.xml`을 제출합니다.

### ④ 다음 웹마스터도구

1. [webmaster.daum.net](https://webmaster.daum.net)에서 사이트를 등록하면 robots.txt에 넣을 한 줄(`#DaumWebMasterTool:...`)을 줍니다.
2. 그 한 줄 전체를 `site.json`의 `"daumRobotsLine"`에 넣습니다.

### ⑤ 빙(선택)

Bing Webmaster Tools는 구글 서치 콘솔에서 가져오기를 쓰면 따로 확인할 필요가 없습니다. 직접 등록한다면 HTML 태그 값을 `"bing"`에 넣습니다.

> 등록했다고 바로 검색에 나오지는 않습니다. 보통 수집 → 색인 → 노출까지 몇 주가 걸립니다.

## 3. 정식 도메인을 연결할 때

1. Cloudflare Pages 프로젝트 → Custom domains에서 도메인을 연결합니다.
2. `site.json`의 `"url"`을 새 주소로 바꿉니다. (예: `"https://yeoljeongsanghoe.kr"`) 끝에 `/`는 붙이지 않습니다.
3. 검색엔진에는 새 주소로 다시 등록하고 사이트맵을 제출합니다.

모든 페이지의 대표 주소(canonical), 사이트맵, RSS가 새 주소로 자동으로 바뀝니다.

## 4. 상회보 글 운영

검색 노출은 결국 글이 쌓여야 늘어납니다. **격주에 한 편**을 목표로 하세요. 상회보 담당 운영진이 맡으면 좋습니다.

### 글 올리는 법 (GitHub 웹에서)

1. 저장소에서 `content/journal` 폴더로 들어가 **Add file → Create new file**을 누릅니다.
2. 파일 이름을 영문으로 짓습니다. 이 이름이 주소가 됩니다. 예: `first-hire.md` → `/journal/first-hire`
3. 맨 위에 아래 앞머리를 붙이고, 그 아래에 본문을 씁니다.

```
---
title: 첫 직원, 언제 뽑아야 할까
description: 검색 결과에 보일 설명. 핵심 키워드를 앞쪽에 넣고 80~110자로 씁니다.
date: 2026-11-23
category: 장사 이야기
keywords: 첫 직원 채용, 자영업자 채용, 1인 사업자 직원
image: packing
---
본문 첫 문단...

## 소제목

문단...

- 목록
- 목록

:::note
글 끝에 넣는 열정상회 안내 상자. [링크 글자](/programs) 처럼 링크를 넣을 수 있습니다.
:::
```

4. Commit changes를 누르면 1~2분 뒤 상회보 목록, 홈, 사이트맵, RSS에 자동으로 반영됩니다.
5. 아직 공개하지 않을 글은 앞머리에 `draft: true`를 넣어 두세요.
6. `image`는 글 머리와 상회보 목록, 공유 미리보기에 쓰는 대표 그림입니다. `tools/images.js`에 있는 그림 이름(`hanjan`, `stall`, `toolbox` 등)을 적거나, 관리자 화면에서 올린 사진 주소(`/assets/img/journal/...jpg`)를 적습니다. 직접 올린 사진이면 `imageAlt: 사진 설명`도 한 줄 넣어 주세요. 빼도 글은 올라갑니다.

### 좋은 글의 기준

- 제목에 사람들이 실제로 검색하는 말을 넣습니다. ("첫 직원 채용 시기"처럼)
- 첫 문단에서 이 글이 무엇을 알려 주는지 바로 말합니다.
- 소제목(##)을 3개 이상 둡니다. 글 옆에 차례가 자동으로 생깁니다.
- 통계나 제도는 출처를 글 끝에 적습니다. 지원사업처럼 해마다 바뀌는 정보는 공고 원문을 확인하라고 덧붙입니다.
- 상단에서 나온 이야기를 쓸 때는 당사자 동의를 받고 사람과 회사를 알 수 없게 바꿉니다(헌장 2조).
- 글 끝 안내 상자에서 관련 페이지(대상별 페이지, 프로그램, 장날)로 연결합니다.

## 5. 다른 채널과 함께 쓰기

- **네이버 블로그**: 네이버 검색에서는 블로그 글이 잘 보입니다. 상회보 글의 요약과 핵심 문단을 블로그에 올리고, 전체 글은 홈페이지로 연결하세요. 블로그 주소는 `site.json`의 `contact.naverBlog`에 넣으면 사이트 정보에도 연결됩니다.
- **인스타그램**: 장날 일정과 상회보 글 요약 카드를 올립니다. 주소는 `contact.instagram`에 넣습니다.
- **카카오톡 채널**: 문의 창구로 쓰기 좋습니다. `contact.kakaoChannel`에 넣으면 바닥글에 나옵니다.

같은 글을 그대로 복사해 여러 곳에 올리면 중복 문서로 보일 수 있습니다. 다른 채널에는 요약과 링크를 올리세요.

## 6. 매달 확인할 것

- 서치어드바이저 **리포트 → 검색 노출**과 서치 콘솔 **실적**에서 어떤 검색어로 들어오는지 확인합니다.
- 노출은 많은데 클릭이 적은 페이지는 제목과 설명을 고칩니다. (`tools/pages.js`, 글은 앞머리의 title·description)
- 수집 오류가 있는지 확인합니다.
- 신청서의 "알게 된 경로"에서 네이버 검색, 구글 검색, 상회보 글을 고른 비율을 봅니다. 검색 유입이 실제 가입으로 이어지는지 알 수 있습니다.

## 7. 이미지를 넣을 때

이미지 제작 지시서대로 만든 그림을 넣을 때는 `public/assets/img/` 아래에 넣고, 그림마다 무엇을 보여 주는지 한 문장으로 alt를 적습니다. 예: `alt="둥근 탁자에 둘러앉아 이야기하는 장날 모습 일러스트"`. 사진 용량은 한 장에 300KB 아래로 줄여 올립니다.
